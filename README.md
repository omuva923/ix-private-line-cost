## 云前置专线到底是什么？为什么它和普通专线不是一个价

Mkcloud 的产品分两种接入方式，这直接决定了价格结构：

- **直连款（IEPL / IPLC）**：入口绑定一个省份，你从本地网络直接连入口 IP。广港、沪港、沪日、沪美这些产品线都属于这一类。价格里已经包含接入成本。
- **IX 款（上云互联优化专线）**：入口不限省份，但必须从受支持的云厂机器和网络连入，也就是常说的“云前置”。深港、沪港、沪日、沪美四个方向都有对应的 IX 产品。

IX 的价格逻辑就是在这里分岔的：套餐本身便宜（深港 158 元/月起），但你需要一台符合条件的云厂 BGP 机器作前置，那台机器的钱、流量钱、管理成本都要自己算进去。官方知识库明确提醒“IX 套餐单价不能只看标价”，这是实话，不是免责套话。

前置机的支持范围也有硬性规定：深圳入口支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云华南；上海入口在前面基础上还支持 UCloud 华东。普通 BGP 主机不能代替云前置，这点别抱侥幸心理。

## 158 元的深港 IX，实际总成本怎么算

以最便宜的深港上云互联优化专线为例，官方标价 ¥158/月 对应的配置是 2核4G、40GB SSD、500Mbps 峰值、2TB 月流量。真正要花的钱分三块：

1. **专线套餐本身**：¥158/月。
2. **云前置机**：一台支持范围内的云厂 BGP 机器，价格取决于你选哪家云厂、什么配置，这部分 Mkcloud 不收，但省不掉。
3. **潜在流量支出**：计量型套餐按上行、下行双向统计，超量后服务暂停，可以自助购买流量重置，或者提交工单补差价升级套餐。

有个容易误判的点：2TB 月流量看起来很多，但双向合计意味着你传 500GB 上去、拉 500GB 下来，就是 1TB 没了。如果业务是大文件上传，实际能用的“量”要按一半预估。反过来，如果只是后台操作和网页访问，2TB 相当宽裕。

历史活动里这款套餐有过 ¥126/月 的折后价（优惠码 CLOUD-2T-NEW，循环8折），但官方已标注该活动结束，别用历史折后价做预算，认准现价 ¥158。

如果你本来就在用阿里云、腾讯云这些大厂的国内机器，前置机成本是沉没成本，IX 款的性价比会明显更高；如果要从零买一台前置机，建议先把那台机器的月费加进去，再和广港直连款的 ¥228 对比。

## 共享和独享的价格差距，到底差在哪

以沪港方向为例，官方给过一组可以直接对比的数据：

- **共享入门**：1核2G、20GB、200Mbps 峰值、1024GB 月流量，月付 ¥288，已确认季付 ¥864、年付 ¥3456。
- **独享入门**：2核4G、40GB、5Mbps、不限流量，月付 ¥388。

差价 100 元，但两种计费方式对应的资源完全不同。共享款的 200Mbps 是**峰值**，官方明确“不保证持续跑满”；独享款的 5Mbps 是**配置速率**，理论上可以长时间稳定跑满，且不限流量。短时间、爆发式上传适合共享；几小时不停的持续传输（比如直播推流、大批量同步）独享更合适。官方知识库特意强调“不能说 5Mbps 独享一定比 200Mbps 共享快”——判断依据是你的任务曲线，不是数字大小。

另外有个反常识的点：共享和独享指的只是**带宽模式**。无论选哪种，每台 VPS 都分配 1 个独立入口 IP 和 1 个独立出口 IP，不存在“共享款共用 IP 池”这回事。

## 那些标价上看不到的成本和规则

这部分是竞品文章经常略过、但实际下单最容易出问题的地方，逐条列清楚：

- **实名认证**：个人用户需要提供手机号、姓名和身份证号，依据《网络安全法》第二十四条的要求。也就是说这不是完全匿名的服务。
- **升降级规则**：都要走工单，降级到更低价格套餐时差价不退。
- **退款政策**：仅质量问题支持退款，需要在工单里提交具体的延迟、速度数据作证据，由 Mkcloud 审核判断；开通后不支持换到其他地域。
- **SLA**：默认无 SLA 保证，需要可用性承诺的要单独询价定制。
- **出口方向**：出口 IP 只用于向外访问，不接受外部连入。这意味着专线 VPS 不能当公开网站源站、不能收支付回调、不能跑游戏服务端。有第三方测评提到 Mkcloud 的出口 IP 质量较干净（欺诈检测值为 0），适合店铺后台和 API 访问这类出站业务，但官方口径是“不保证原生 IP 和流媒体解锁”，下单前想清楚用途。
- **快照和备份**：官方不把快照、备份作为已提供能力，重要数据自己安排。

## 几个高频问题

**云前置专线 158 元和广港 228 元怎么选？**
看你的前置条件。已有受支持云厂机器的，深港 IX 更便宜、端内延迟同为 1~2ms；没有云厂机器、或者不想多管一台前置机的，广港直连加 70 块省心很多。

**共享流量超了会怎样？**
服务暂停，不会产生流量账单。可以自助购买流量重置，或者补差价升级套餐，两种都行，看剩余周期哪个划算。

**为什么沪港独享 5Mbps 要 388 元？**
你买的是持续速率和不限流量，不是带宽峰值。如果换算成按量计费，长时间满速传输的流量费用远超这个数，官方知识库里有一篇专门讲这个定价逻辑，感兴趣可以自己去翻。

**价格表里的延迟是全程延迟吗？**
不是。1~2ms、21ms 这些都是端内参考值，你的真实体验还要加上本地到入口、出口到目标网站两段路径。深圳本地访问深港入口确实快，但如果你人在别的省份，本地到前置那段就是另一回事了。

**能开发票、签合同吗？**
SLA、路由定制这类服务要单独通过工单或官方渠道询价，默认套餐不含这些。企业采购建议先把服务边界聊清楚再付钱。
